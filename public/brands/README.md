# Brand marks

These marks belong to their owners. Telko is not affiliated with them and uses them only to identify the operator or service an offer belongs to.

| File | Owner | Source | Retrieved |
|---|---|---|---|
| `yas.svg` | Yas Togo | https://yas.tg | 2026-10-18 |
| `mixx.svg` | Yas Togo (Mixx by Yas) | https://yas.tg/mixx-by-yas/ | 2026-10-18 |
| `moov.png` | Moov Africa Togo | https://moov-africa.tg (site icon) | 2026-10-18 |

Logos are displayed only when `SHOW_BRAND_LOGOS` is enabled in `src/config.ts`. When it is disabled, or when a brand has no logo (`"logo": null` in `operators.json`), the site shows the brand's badge instead.

If you represent one of these brands and want a mark removed or updated, open an issue or a private security report.
