# Code of Conduct

Telko adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers, and keep discussions about the work. Harassment, discrimination and personal attacks are not accepted in issues, pull requests or any project space.

## Reporting

Report unacceptable behavior privately to the maintainers by opening a confidential security advisory on the repository, or by email once a project address is published. Reports are handled confidentially.
